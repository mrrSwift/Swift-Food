# Swift Food
## Digital menu for cafes and restaurants

## 🟡Warning: This app is still under development and needs a lot of improvement and refactoring.

A full-stack TypeScript monorepo digital menu with using Bun, Hono, Vite, and React.

## Why Swift Food?

First of all, it is open source.
Everything is being updated and developed.
Fast and simple.
Cutting edge technology.

## Features

- **Full-Stack TypeScript**: End-to-end type safety between client and server
- **Monorepo Structure**: Organized as a workspaces-based monorepo with Turbo for build orchestration
